# Certificates

Put your certificate files in this folder using EXACTLY these names (PDF is best; .png, .jpg, .jpeg or .webp also work):

- excel-data-preparation-microsoft.pdf       (Preparing Data for Analysis with Excel, Microsoft / Coursera)
- introduction-to-ai-ibm.pdf                 (Introduction to Artificial Intelligence, IBM / Coursera)
- ai-skills-passport-ey-microsoft.pdf        (AI Skills Passport, EY and Microsoft)
- front-end-web-development-microsoft.pdf    (Front-End and Web Development, Microsoft)
- full-stack-django-ai-edunet-ey.pdf         (Full Stack Web Development with Django and AI Tools, Edunet Foundation with EY)

When a visitor clicks "View certificate" on the portfolio, the matching file opens in a new tab.
